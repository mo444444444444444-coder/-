# أدواتك | Adwatak

منصة عربية لأدوات يومية تعمل داخل المتصفح، من تطوير **محمد شعبان محارب**.

## الموجود حاليًا
- ضغط وتحويل الصور إلى WebP / JPG / PNG.
- تغيير أبعاد الصور.
- اختيار الألوان ونسخ HEX وRGB.
- قراءة وتشغيل ملفات الفيديو والصوت المحلية.
- محاولة استخراج الصوت إلى WAV للملفات التي يستطيع المتصفح فك ترميزها.
- تجهيز مستند للطباعة أو الحفظ بصيغة PDF من المتصفح.
- قراءة ملفات TXT وCSV وJSON.
- أدوات النصوص وJSON وBase64.
- آلة حاسبة، تحويل وحدات، مولد كلمات مرور، QR، وتحويل التاريخ إلى Unix timestamp.
- تصميم متجاوب مع الهاتف والتابلت والكمبيوتر، ووضع فاتح/داكن.

## نشر الموقع
هذا موقع ثابت HTML/CSS/JavaScript، ويمكن نشره عبر GitHub Pages. GitHub Pages لا يشغّل خادمًا أو واجهات خلفية، لذلك أدوات الذكاء الاصطناعي الثقيلة أو معالجة الفيديو من روابط خارجية تحتاج خدمات مستقلة، ولا يجب عرضها كميزات فعالة قبل تنفيذها واختبارها.

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط Save.
4. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

## مهم قبل النشر العام
اسم المستودع الحالي هو `-`، وهو اسم مؤقت غير مناسب كرابط عام. غيّره من **Settings → General → Repository name** إلى `adwatak` قبل تفعيل Pages؛ بعدها يكون الرابط المتوقع:
`https://mo444444444444444-coder.github.io/adwatak/`

## ملاحظات واقعية
- معالجة الصور والنصوص تجري محليًا في المتصفح قدر الإمكان.
- استخراج الصوت يعتمد على دعم المتصفح للترميز وحجم الملف والذاكرة.
- أداة QR تحتاج اتصالًا لتحميل مكتبتها الخارجية عند الاستخدام.
- حفظ PDF يتم من خلال نافذة الطباعة في المتصفح.
- لم تُختبر جميع الأدوات على كل جهاز ومتصفح؛ يجب إجراء اختبار فعلي قبل اعتبار الموقع جاهزًا 100%.
